# ID Contable (ID Studio) — Instrucciones del repositorio

Aplicaciones contables para el mercado chileno. Marca **ID Contable**, versiones Auditor, Educa y Empresa.

| Carpeta | Estado |
|---------|--------|
| `auditor/` | **Activo.** SaaS contable multi-cliente para estudios contables. Protocolo de trabajo: `auditor/CLAUDE.md` |
| `educa/` | En pausa (versión antigua de auditor) |
| `empresa/` | En pausa |

## Preferencias del usuario
- Respuestas breves, precisas y en español.
- Antes de cada acción solicitada: **planificar y esperar confirmación**.
- Ser objetivo: comparar con el mercado y señalar fallas o cosas a mejorar.
- Trabajar solo en `auditor/` salvo que el usuario pida otra cosa.
